# Product Definition - Malgo

## Vision
Malgo is an experimental platform for programming language research, focusing on the intersection of static typing, sequent calculus-based intermediate representations, and advanced functional programming features like copattern matching and codata.

## Target Audience
- **PL Researchers:** Those interested in exploring new IRs, optimization techniques, and type system extensions.
- **Functional Programmers:** Developers seeking a modern, statically typed functional language with a clear and hackable implementation.

## Core Features
- **Statically Typed:** Malgo features a robust static type system, ensuring safety and enabling powerful abstractions.
- **Sequent Calculus IR:** The compiler pipeline utilizes IRs based on sequent calculus (Core, Flat, Join), providing a formal foundation for optimizations and analysis.
- **Copattern matching and Codata:** First-class support for codata and copattern matching, allowing for elegant definitions of infinite data structures and stateful computations.

## Goals
- **Experimental PL Platform:** Serve as a versatile playground for testing and implementing cutting-edge language features and compiler optimizations.
- **Innovation in IRs:** Push the boundaries of how sequent calculus can be used to represent and optimize functional programs.

## Roadmap & Current Focus
- **New Features:** Actively extending the type system and adding new syntax to support more expressive programming patterns.
- **Core Refinement:** Continuous improvement of the compiler pipeline and runtime performance.
