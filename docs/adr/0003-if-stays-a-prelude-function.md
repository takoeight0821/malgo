# ifはPrelude関数のまま保つ

`if`は`runtime/malgo/Prelude.mlg`に定義された通常の関数（`Bool -> {a} -> {a} -> a`）で、コンパイラの特別構文ではない。`unless`/`cond`も同じ「サンク引数を取る関数」という仕組みで定義されており、nix-configはこの仕組みを使って自分たちの制御構文を必要に応じて調整してきた（`unless`の型を絞った#432など）。

[0001](./0001-core-syntax-sugar-over-macros.md)の可読性改善（レコード更新式・単一定義・ガード節・文字列補間）は、`if`をコンパイラ組み込みの特別構文にすることを含まない。`if`/`unless`/`cond`はPrelude関数のまま保ち、ユーザーが同じ仕組みで自分の制御構文を定義できる余地を残す。

## Consequences

- `{ }`の多義性（if分岐・関数の複数節・letブロックが同じ記法を共有する）を解消する場合、`if`を特別扱いせずに済む、記法レベルの視覚的な区別を探る必要がある。この具体的な記法は詳細設計を別セッションに残す。
